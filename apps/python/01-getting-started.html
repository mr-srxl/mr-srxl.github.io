01 · Getting started

Python is one of the kindest languages to learn. It reads almost like English, and the little things you write early still feel useful later. Before writing a single line, let's get it running — that's the only setup you'll ever need.

Install & run

  • Windows / macOS: download the installer from python.org and run it. On Windows, tick "Add Python to PATH".
  • Linux: Python is almost always preinstalled. Check with python3 --version.
  • Open a terminal and type python (or python3). You'll see a >>> prompt. That's the REPL — type Python, get answers immediately.

Your first program

# My first program
print("Hello, meadow.")

name = "Sina"
print("Hello,", name)
Hello, meadow. Hello, Sina

print() shows things. Lines starting with # are comments — the computer ignores them, but you'll read them later and be grateful.

How to name a variable

A variable is a name that points at a value. Python doesn't care much about how you name them, but other humans (including future-you) do. Here are the rules and the conventions.

The hard rules

  • Must start with a letter or an underscore — never a digit.
  • Can contain letters, digits, and underscores only (no spaces, no dashes).
  • Case-sensitive: age, Age, and AGE are three different variables.
  • Can't be a reserved keyword like if, for, class, return, True, None, import.

The soft conventions (the ones that make code readable)

  • snake_case for ordinary variables and functions: user_name, total_price, is_ready.
  • ALL_CAPS for constants that never change: MAX_RETRIES = 3, PI = 3.14159.
  • _single_underscore at the start means "internal, please don't touch": _cache, _helper.
  • __dunder__ (double underscores on both sides) is reserved for Python's own magic: __init__, __name__.
  • Be descriptive. user_age beats ua. total_price beats tp.
  • Don't shadow built-ins. Naming a variable list or print will hurt later.

Good and bad, side by side

# Bad — cryptic
a = 30
tp = 99.9
x2 = True

# Better — descriptive
user_age = 30
total_price = 99.9
is_logged_in = True

# Constants
MAX_LOGIN_ATTEMPTS = 3

# Private helper (used internally by a module)
_cleanup = "internal helper"
Try this: open the REPL, make five variables describing yourself — name, age, city, favourite_language, is_learning — and print each one. Then rename one of them to something clearer and see if it reads better.
