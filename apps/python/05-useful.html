05 · enumerate, zip, sorted

Three built-ins that turn clumsy loops into elegant ones. Learn them once, use them forever.

enumerate — index and value together

When you loop over a list and you also want to know where you are, use enumerate. No more i = 0; i += 1.

flowers = ["daisy", "poppy", "iris"]

for i, flower in enumerate(flowers):
    print(i, flower)

# Start counting from 1 instead of 0:
for i, flower in enumerate(flowers, start=1):
    print(f"{i}. {flower}")
0 daisy 1 poppy 2 iris 1. daisy 2. poppy 3. iris

zip — walk two (or more) lists together

names = ["Sina", "Sara", "Reza"]
ages  = [23, 27, 31]

for name, age in zip(names, ages):
    print(f"{name} is {age}")

# Build a dict from two lists:
people = dict(zip(names, ages))
# {'Sina': 23, 'Sara': 27, 'Reza': 31}

zip stops at the shorter list — so unequal lengths won't error, they'll just truncate. Use zip(..., strict=True) in Python 3.10+ if you want it to complain instead.

sorted — with a key

words = ["banana", "apple", "cherry"]
sorted(words)                                  # alphabetical
sorted(words, key=len)                         # by length
sorted(words, reverse=True)                    # descending

# Sort a list of dicts by one field:
users = [
    {"name": "Sina", "age": 23},
    {"name": "Sara", "age": 27},
    {"name": "Reza", "age": 19},
]
sorted(users, key=lambda u: u["age"])
# Reza, Sina, Sara

The key is a small function applied to each item before comparing. lambda u: u["age"] means "for each user u, use u['age'] as the sort key".

List comprehensions — building lists in one line

# Long form:
squares = []
for n in range(6):
    squares.append(n * n)

# Same thing, one line:
squares = [n * n for n in range(6)]

# With a filter:
evens = [n for n in range(20) if n % 2 == 0]

# Applied to a list of names:
shouting = [name.upper() for name in ["Sina", "Sara"]]

Comprehensions aren't just shorter — they're often clearer once your eye is used to them. If a comprehension takes more than one line to read, though, write the loop.
