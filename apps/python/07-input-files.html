07 · User input & files

Two of the most useful skills: talking to the person running your program, and reading/writing files on disk.

Asking for input

name = input("What's your name? ")
print(f"Hello, {name}.")

# input() always returns a string — convert when you need a number:
age_text = input("How old are you? ")
age = int(age_text)
print(f"Next year you'll be {age + 1}.")

Validating input in a loop

People type strange things. A while True loop with a try/except is the standard way to ask again politely:

while True:
    text = input("Enter a number: ")
    try:
        number = int(text)
        break               # success — leave the loop
    except ValueError:
        print("That's not a number. Try again.")

print(f"You entered {number}.")

Reading a file

The with block opens a file and closes it automatically when done — even if something goes wrong. Use it always.

# Read the whole file at once
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# Read line by line
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

Writing a file

# "w" overwrites the file
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("First line\n")
    f.write("Second line\n")

# "a" appends instead
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("One more line\n")

Modes at a glance

"r"read (default) — errors if file doesn't exist
"w"write — creates or overwrites
"a"append — creates or adds to end
"r+"read and write, file must exist
"rb" / "wb"binary mode (images, etc.)

Working with paths

Absolute paths are safer than relative ones if your script might run from anywhere:

from pathlib import Path

home = Path.home()
notes = home / "notes.txt"     # joins safely
print(notes.exists())

with notes.open("a", encoding="utf-8") as f:
    f.write("Another line\n")

# List files in a folder
for file in Path(".").glob("*.txt"):
    print(file)

JSON — structured data in files

Python ships with JSON support. It's the easiest way to save structured data.

import json

# Write
data = {"name": "Sina", "languages": ["Python", "C"]}
with open("profile.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2)

# Read
with open("profile.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)
    print(loaded["name"])   # 'Sina'
