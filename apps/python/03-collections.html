03 · Lists, tuples, dicts, sets

Four containers, each with its own personality. Choosing the right one makes code shorter and clearer.

Lists — ordered and mutable

Use lists when you have many of the same kind of thing and you'll add or remove items.

garden = ["rose", "tulip", "daisy"]

garden.append("iris")         # add to end
garden.insert(0, "sunflower") # insert at position 0
garden.remove("tulip")        # remove by value
last = garden.pop()           # remove & return last
garden[0] = "lily"            # replace by index

print(garden[0])              # 'lily'
print(garden[-1])             # last item
print(len(garden))            # how many
print("rose" in garden)       # True/False

Sorting and reversing

numbers = [3, 1, 4, 1, 5, 9, 2]
numbers.sort()                # in place, ascending
numbers.sort(reverse=True)    # descending
sorted(numbers)               # returns a NEW list
numbers.reverse()             # in place

Tuples — ordered but immutable

Use tuples when the collection shouldn't change — a coordinate, a fixed pair, a record. They're faster than lists and safer as dict keys.

point = (3, 7)
x, y = point                  # unpacking
print(x, y)                   # 3 7

# A one-element tuple needs a comma:
single = (42,)
not_a_tuple = (42)            # this is just the number 42

Dictionaries — key/value pairs

Use dicts when you need to look things up by name, not by position.

user = {
    "name": "Sina",
    "age": 23,
    "city": "Tehran",
}

user["email"] = "sina@example.com"   # add
user["age"] = 24                     # update
del user["city"]                     # remove

user.get("phone")                    # None (no error)
user.get("phone", "unknown")         # 'unknown' as default

for key, value in user.items():
    print(key, "->", value)

Sets — unique, unordered

Use sets for uniqueness and fast membership checks.

tags = {"python", "linux", "red team"}
tags.add("c2")
tags.discard("linux")

a = {1, 2, 3}
b = {3, 4, 5}
a | b     # union          {1,2,3,4,5}
a & b     # intersection   {3}
a - b     # difference     {1,2}

# Remove duplicates from a list:
list_with_dupes = [1, 2, 2, 3, 3, 3]
unique = list(set(list_with_dupes))   # [1, 2, 3]

Which one should I use?

List[1, 2, 3] — ordered, changeable, allows duplicates
Tuple(1, 2, 3) — ordered, fixed, safer as keys
Dict{"k": "v"} — lookup by name
Set{1, 2, 3} — unique items, fast in
