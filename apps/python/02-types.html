02 · Types & strings

Python has a small handful of basic types. Learn them, and everything else clicks into place.

The five you'll meet first

name    = "Sina"      # str   — text
age     = 23          # int   — whole number
height  = 1.78        # float — decimal
is_ok   = True        # bool  — True or False
nothing = None        # None  — the absence of a value

print(type(name), type(age), type(height))
<class 'str'> <class 'int'> <class 'float'>

Converting between types

number_as_text = "42"
number        = int(number_as_text)   # 42
text          = str(3.14)             # "3.14"
decimal       = float("1.5")          # 1.5

print(number + 1)         # 43
print(number_as_text + "!")  # "42!"

Strings in depth

Strings are your most-used type. Here are the tools you'll reach for daily.

greeting = "Hello, meadow"

# Length
len(greeting)                  # 13

# Indexing (starts at 0) and slicing
greeting[0]                    # 'H'
greeting[-1]                   # 'w'
greeting[0:5]                  # 'Hello'
greeting[7:]                   # 'meadow'

# Methods — they return a new string, they don't mutate
greeting.upper()               # 'HELLO, MEADOW'
greeting.lower()               # 'hello, meadow'
greeting.replace("meadow", "world")   # 'Hello, world'
"  hello  ".strip()            # 'hello'
"a,b,c".split(",")             # ['a', 'b', 'c']
"-".join(["a", "b", "c"])      # 'a-b-c'
"meadow".startswith("me")      # True
"meadow".endswith("ow")        # True
"me" in "meadow"               # True

f-strings — the cleanest way to build text

name = "Sina"
age  = 23

print(f"{name} is {age} years old.")
print(f"Next year: {age + 1}")
print(f"Pi is roughly {3.14159:.2f}")   # two decimal places
print(f"{name:>10}")                    # right-align in width 10
print(f"{name:<10}|")                   # left-align in width 10
Sina is 23 years old. Next year: 24 Pi is roughly 3.14 Sina Sina |

Numbers

7 + 3       # 10   addition
7 - 3       # 4    subtraction
7 * 3       # 21   multiplication
7 / 3       # 2.333… float division
7 // 3      # 2    integer division (floor)
7 % 3       # 1    remainder (modulo)
7 ** 3      # 343  exponent

round(3.14159, 2)   # 3.14
abs(-7)             # 7
max(1, 5, 3)        # 5
min(1, 5, 3)        # 1
