A Python course

Simple things, done well — ten short chapters.

Python reads almost like English and comes with everything you need. This course walks you from "what is a variable" to "write a small notes app" in ten focused chapters. Every example is short enough to run right now.

Before you start: install Python from python.org, open a terminal, type python (or python3 on Linux/macOS), and paste any snippet from these pages into it. No files, no editor — just you and the interpreter.
01 Getting started
Install, run, print, comments — and how to name variables properly.
 02 Types & strings
Numbers, text, booleans, None — and the string tools you'll use every day.
 03 Lists, tuples, dicts, sets
The four containers — when to use each, with side-by-side examples.
 04 Control flow
if / elif / else, for and while loops, range, break, continue.
 05 enumerate, zip, sorted
Three built-ins that make your loops and sorting beautiful.
 06 Functions
def, parameters, defaults, *args, **kwargs, scope, and lambdas.
 07 Input & files
Ask the user for data, then read and write real files on disk.
 08 Modules & packages
Imports, pip, virtual environments, and what requirements.txt really is.
 09 Errors & exceptions
try / except / finally, raising your own, and the errors you'll meet most.
 10 A small project
A file-based notes app that ties everything together.
