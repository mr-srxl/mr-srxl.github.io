04 · Control flow

Programs become interesting when they can choose and repeat. That's what if and for are for.

Deciding

temperature = 18

if temperature > 25:
    print("Warm outside.")
elif temperature > 15:
    print("Mild. Nice for a walk.")
else:
    print("Cold. Bring a jacket.")
Mild. Nice for a walk.

The indentation (those four spaces) is part of the language — it tells Python what belongs inside the block. Use four spaces per level, always.

Comparisons and logic

x == y     # equal
x != y     # not equal
x <  y     # less than
x >= y     # greater or equal

# Combine conditions
if age >= 18 and has_id:
    print("You may enter.")

if day == "Saturday" or day == "Sunday":
    print("Weekend.")

if not is_raining:
    print("Go outside.")

Truthy and falsy

Every value in Python is "truthy" or "falsy". The empty/false ones are:

FalsyFalse, 0, 0.0, "", [], {}, set(), None
Truthyeverything else — including "0" and [0]

This lets you write if items: instead of if len(items) > 0:.

Repeating

for loops

for i in range(3):
    print("step", i)

for flower in ["daisy", "poppy", "iris"]:
    print("-", flower)
step 0 step 1 step 2 - daisy - poppy - iris

range() — three forms

range(5)          # 0 1 2 3 4
range(2, 6)       # 2 3 4 5
range(0, 10, 2)   # 0 2 4 6 8

while loops

count = 0
while count < 3:
    print("count is", count)
    count += 1

While loops run until their condition becomes false. They're the right tool when you don't know in advance how many iterations you need.

break and continue

for n in range(10):
    if n == 5:
        break      # exit the loop entirely
    if n % 2 == 0:
        continue   # skip to next iteration
    print(n)

# Prints: 1, 3
Try this: print all numbers from 1 to 20 that are divisible by 3. Then do it again with a while loop.
