06 · Functions

A function is a named piece of logic you can call whenever you need it. They keep code tidy, testable, and easy to change.

The basics

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}."

print(greet("Sina"))
print(greet("Sina", "Good evening"))
Hello, Sina. Good evening, Sina.

greeting="Hello" is a default value — used when you don't pass one. return sends a value back. A function without return returns None.

Returning more than one thing

def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 4, 1, 5, 9])   # actually returns a tuple
print(low, high)                            # 1 9

Variable number of arguments

def total(*numbers):
    return sum(numbers)

total(1, 2, 3)           # 6
total(10, 20, 30, 40)    # 100

def show_info(**details):
    for key, value in details.items():
        print(f"{key}: {value}")

show_info(name="Sina", age=23, city="Tehran")

*args gathers extra positional arguments into a tuple. **kwargs gathers extra keyword arguments into a dict. You'll see both a lot in libraries.

Scope — where variables live

total = 0

def add(n):
    total = 100     # this is a NEW local variable
    return n + 1

add(5)
print(total)        # still 0

counter = 0
def bump():
    global counter  # explicitly reach outside
    counter += 1

bump()
print(counter)      # 1

Python looks for a variable in the local scope first, then outward. If you need to modify an outer variable inside a function, use global — but do it sparingly, or your code becomes hard to reason about.

Docstrings — leaving notes for future-you

def area(width, height):
    """Return the area of a rectangle."""
    return width * height

print(area.__doc__)

A triple-quoted string as the first line of a function becomes its documentation. Editors show it as a tooltip; help() reads it.

Lambda functions

A lambda is a tiny function with no name. Perfect for a one-line "use this as the key" moment.

square = lambda x: x * x
print(square(5))        # 25

# Most common use: sort keys (see chapter 5)
sorted(users, key=lambda u: u["age"])

If a lambda grows past one line, write a real function instead.
