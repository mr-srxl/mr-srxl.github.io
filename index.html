The path so far

A quiet walk through the fundamentals — one step at a time.

I like learning things that are useful. Not to collect badges, but so I can actually use them. Here's the road I've been walking — and the road still ahead.

  1. Network+

    Working with computers, learning the fundamentals — how the pieces connect, and how they talk to each other.

  2. A little of CCNA

    Just enough to see how networks are really put together. Studied for fun — turned out to be one of the most useful things I've learned.

  3. LPIC-1

    Learning Linux properly — configuring services, getting comfortable on the command line, making the system feel like home.

  4. A little HTML & CSS

    Designing a login page. Small — but the first time something I made was actually visible to someone else.

  5. Python

    It's easy to start, and it's useful. Learning it to build a small tool — for myself, not for a portfolio.

  6. Build a website

    Learning about HTTP, HTTPS and other protocols along the way. Understanding what actually happens when you open a page.

  7. A little about databases

    Just enough to understand how information is stored, moved around, and found again.

  8. CEH & PWK / PWD

    The next quiet step. Learning the discipline — then learning to break it gently.

The trick

Learn different things — and then use them together to do your own purpose. Nothing is wasted. A little HTML makes the protocols make sense. A little Python makes the tooling make sense. A little philosophy makes the rest make sense.
